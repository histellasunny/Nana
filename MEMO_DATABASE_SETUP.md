# Shared memo setup (Supabase)

The current GitHub Pages site is static. It cannot securely store shared notes by itself. To enable notes visible to everyone with the link, connect a Supabase project.

1. Create a free project at https://supabase.com/ and keep the project URL and anon/public key. Never put a service_role key in browser code.
2. In SQL Editor, run:

```sql
create table public.travel_memos (
  id bigint generated by default as identity primary key,
  day integer not null,
  author text not null default 'Guest',
  body text not null,
  created_at timestamptz not null default now()
);
alter table public.travel_memos enable row level security;
create policy "Anyone can read travel memos" on public.travel_memos for select using (true);
create policy "Anyone can add travel memos" on public.travel_memos for insert with check (char_length(body) between 1 and 2000 and char_length(author) between 1 and 40);
```

3. Add the Supabase URL and anon key to the site's JavaScript and use the Supabase client to read/insert rows. The anon key is designed to be public; RLS policies are the security boundary.
4. Because this setup allows anyone with the link to post, add CAPTCHA/rate limiting and a delete/moderation process before public use. Do not expose a service_role key.

This project currently contains the database setup instructions only; shared memo posting will not work until you create the Supabase project and supply its URL and anon key.
