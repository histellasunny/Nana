# Malaysia & Singapore Travel Guide

이 파일 묶음은 GitHub 저장소 최상위에 모든 파일을 두는 구조입니다.

## 파일 구조
- index.html
- style.css
- app.js
- itinerary.json
- README.md

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` 설정을 사용하세요.

## 중요
이 네 파일은 모두 Repository 최상위에 업로드해야 합니다. css/js/data 폴더를 새로 만들 필요가 없습니다.

## 지도
Leaflet 및 OpenStreetMap 타일을 사용합니다. 지도 검색을 위해 인터넷 연결이 필요합니다. 위치 검색 결과가 불확실한 장소는 지도 핀으로 표시되지 않을 수 있습니다. 경로선은 장소를 잇는 참고용 직선이며 실제 도로 경로가 아닙니다.
